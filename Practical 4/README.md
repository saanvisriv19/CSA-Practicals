Practical 4:
AIM: To write an assembly program that reads two numbers A and B and displays A − B
Tool: CPU Sim 4.0.11 (Java 8 with JavaFX)
Observation: For 18 − 50 the final AC is −32 (FFE0 hex), DR = 18 and PC = 9. For −7 − (−7) the output is 0
Result: The program subtracts two user-entered numbers using the 2's complement; 18 − 50 = −32 and 50 − 18 =32
