Practical 5:
AIM: To write an assembly program that performs AND, OR, NOT, XOR, NOR and NAND on two user entered numbers.
Tool: CPU Sim 4.0.11 (Java 8 with JavaFX)
Result: All six logical operations were simulated using only AND and CMA. For A = 12 and B = 10 the outputs are 
AND = 8, OR = 14, NOT A = −13, NOT B = −11, XOR = 6, NOR = −15, NAND = −9.
